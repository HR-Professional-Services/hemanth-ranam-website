# Hemanth Ranam — Personal Website

Personal technology studio & entrepreneur portfolio for **Hemanth Ranam**.

- **Positioning**: Business Systems • Automation • Software • Trading Technology
- **Live Local Preview**: [http://localhost:3000](http://localhost:3000)
- **Repository**: [https://github.com/hemanthranam/hemanth-ranam-website](https://github.com/hemanthranam/hemanth-ranam-website)

---

## 🚀 Key Features & Architecture

1. **Design Principle**: Less text, more visual information (cards, flows, badges, numbers).
2. **Color Palette**: Clean white background + subtle blue accents + white footer.
3. **Subtle 3D Element**: Lightweight Three.js WebGL geometric core with responsive performance.
4. **Real Photography**: High-resolution executive portrait (`public/images/hemanth-ranam-profile.jpg`).
5. **Consolidated Sections**:
   - `Hero`: Direct headline, small positioning line, and 3D canvas.
   - `About Me`: 2017→2026 track record, 5+ years trading, 2X founder, MBA & CMI Level 7.
   - `Core Services`: 4 categories (Business Systems, Software, Automation, Trading Tech) with execution flow banners.
   - `Tech Stack`: Minimal icon+name grid.
   - `Trading Technology`: 6-step visual pipeline, tags, and compliance notice.
   - `Project Pricing`: Accessible USD ($) project-based starting rates.
   - `Contact`: Concise form, email copy shortcut, and LinkedIn network.
   - `White Footer`: Small, clean footer matching the main site.
   - `WhatsApp CTA`: Floating button with prefilled message (`+917675815245`).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15+ (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **3D Graphics**: Three.js
- **Icons**: Lucide React + custom vectors
- **SEO**: Structured JSON-LD (Schema.org), OpenGraph, dynamic sitemap and robots.txt

---

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Run dev server (default on port 3000)
npm run dev

# Run production build
npm run build
```
