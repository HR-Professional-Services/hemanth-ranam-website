### Tech Stack

- **Framework**: Next.js 15+ (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D Visuals**: Three.js (WebGL)
- **Icons**: Lucide React + Custom Vector Assets
- **Deployment**: Cloudflare Workers
