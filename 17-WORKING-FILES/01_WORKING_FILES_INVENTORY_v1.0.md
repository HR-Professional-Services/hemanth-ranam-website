## 2. Working File Categories
1. **Google Sheets Master Schemas:**

2. **Apps Script Source Libraries:**

3. **Pine Script & MQL5 Working Source:**
   - Source code for TradingView v5 indicators and MetaTrader 5 Expert Advisors (educational & analytical tools).
4. **Mock Test Payloads:**
   - Simulated Stripe webhook JSON payloads (`checkout.session.completed`, `customer.subscription.updated`).
